<h1>Desafio - Desenvolvedor Back-end</h1>

<h2>Descrição</h2>
<p>Este projeto é um desafio técnico para a posição de desenvolvedor back-end. Ele consiste na criação de uma API robusta, eficiente e escalável, utilizando boas práticas de desenvolvimento.</p>

<h2>Funcionalidades</h2>
<ul>
    <li><strong>CRUD Completo</strong>: Implementação das operações de criação, leitura, atualização e exclusão.</li>
    <li><strong>Autenticação e Autorização</strong>: Proteção de endpoints com autenticação via JWT.</li>
    <li><strong>Banco de Dados</strong>: Integração com um banco de dados SQL/NoSQL.</li>
    <li><strong>Validação de Dados</strong>: Utilização de bibliotecas para garantir a integridade das informações.</li>
    <li><strong>Testes Automatizados</strong>: Implementação de testes unitários para garantir confiabilidade.</li>
    <li><strong>Documentação da API</strong>: Swagger ou outra ferramenta para descrever os endpoints.</li>
</ul>

<h2>Tecnologias Utilizadas</h2>
<ul>
    <li><strong>Python</strong> (FastAPI/Django/Flask) ou <strong>Node.js</strong> (Express/NestJS).</li>
    <li><strong>PostgreSQL/MySQL</strong> ou <strong>MongoDB</strong> para armazenamento de dados.</li>
    <li><strong>Docker</strong> para conteinerização do projeto.</li>
    <li><strong>JWT</strong> para autenticação segura.</li>
    <li><strong>Pytest/Jest</strong> para testes automatizados.</li>
</ul>

<h2>Como Rodar o Projeto</h2>
<ol>
    <li><strong>Clone o repositório</strong>: <code>git clone https://github.com/MatheusTSS/Desafio-Desenvolvedor-Back-end.git</code></li>
    <li><strong>Instale as dependências</strong>: Execute <code>pip install -r requirements.txt</code> ou <code>npm install</code>.</li>
    <li><strong>Configure as variáveis de ambiente</strong>: Crie um arquivo <code>.env</code> com as credenciais do banco.</li>
    <li><strong>Execute as migrações</strong>: Para Django, use <code>python manage.py migrate</code>. Para Sequelize, use <code>npx sequelize db:migrate</code>.</li>
    <li><strong>Inicie a aplicação</strong>: <code>python main.py</code> ou <code>npm run start</code>.</li>
</ol>

<h2>Requisitos</h2>
<ul>
    <li>Python 3.x ou Node.js instalado.</li>
    <li>Banco de dados configurado corretamente.</li>
    <li>Docker instalado (opcional).</li>
</ul>
